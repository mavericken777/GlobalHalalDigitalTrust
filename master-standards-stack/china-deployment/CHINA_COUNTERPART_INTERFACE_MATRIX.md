# China Counterpart Interface Matrix

## Purpose

This matrix converts the China HOD discussion into departmental work packages. It is a functional interface map; formal mandates, counterpart names and decision rights must follow the approved government itinerary and written programme charter.

| Domain | Counterpart interface | Questions to resolve | AHTE output | Immediate action |
|---|---|---|---|---|
| National standardisation | SAC / relevant standards bodies | How should Malaysian Halal requirements be represented alongside Chinese standards and terminology? | Standards crosswalk + semantic registry | Nominate technical standards lead |
| Market / food safety | SAMR / relevant authorities | Which traceability, enterprise accountability and product-safety records are available for federation? | Regulatory data adapter | Define data-sharing scope |
| Customs / border | GACC / customs authority | What shipment, inspection, quarantine and release data can be exchanged? | Port/customs gateway contract | Select pilot port/interface |
| Foreign trade | MOFCOM / trade authorities | What trade-facilitation and international cooperation mechanisms apply? | Trade corridor workstream | Define institutional pathway |
| Cyber / data | CAC and applicable local cyberspace authorities | What data may cross border, in what form, under which mechanism? | Data classification + cross-border control plan | Data legal/technical working group |
| Industrial digitisation | MIIT / local industrial authorities | Which factory digital systems can interface with AHTE? | ERP/MES/WMS/QMS/LIMS integration pattern | Select pilot factory stack |
| Conformity / accreditation | Chinese accreditation and certification ecosystem | How should competent conformity evidence and certificates be represented? | Credential/attestation schema | Define participating assessment bodies |
| Local implementation | Beijing / provincial / municipal bodies as applicable | Which pilot sites, demonstration environments and operating approvals are needed? | Pilot execution plan | Establish local programme office |
| Logistics | Carrier / port / warehouse operators | How are physical custody and seal events digitally bound? | Custody + seal event API | Run Shipment 001 rehearsal |
| Laboratory | Qualified laboratories | Which methods, sample chains and result formats are accepted? | Method registry + result schema | Nominate labs |
| GCC destination | Importers + destination authorities | What destination-specific evidence and import events are required? | Jurisdiction rule pack | Define Saudi/UAE first-wave requirements |

## HOD decision template

Each meeting should end with five explicit fields:

1. **Owner** - named organisation/person accountable.
2. **Decision** - what was agreed.
3. **Data** - what information is required/exchanged.
4. **System** - which AHTE or counterpart interface implements it.
5. **Date** - target completion/review milestone.

## Current official context

- SAMR states that it coordinates food-safety supervision, establishes inspection/supervision mechanisms across production, circulation and consumption, and works on food traceability. https://english.samr.gov.cn/AboutSAMR/Mainresponsibility/index.html
- MOFCOM's mission includes domestic/foreign trade policy, international economic cooperation and foreign trade promotion. https://english.mofcom.gov.cn/About/
