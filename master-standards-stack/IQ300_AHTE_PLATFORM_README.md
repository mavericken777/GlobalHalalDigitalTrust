# AHTE operating references

This directory contains project operating references for the Amanah/AHTE end-to-end halal assurance platform. The current project model is maintained in the root [README](../README.md), [STATUS](../STATUS.md), and [REPO_INDEX](../REPO_INDEX.md).

## Reference areas

- `iq300-all-jakim-ms/` — standards applicability register and related control/evidence references.
- `iq300-full-matrix/` — control catalogue, process flows, evidence profiles and audit references.
- `process-flow-infographics/` — process-flow visuals and their generator.
- `CHINA_EXECUTION_PACK/` — China-to-GCC direct product journey, operational workflows, event catalogue, API contracts and schemas.
- `china-deployment/` — data-sovereignty, manufacturer onboarding and port/customs integration references.

## Assurance journey

```text
Organisation and premises → products/SKUs and suppliers/materials → applicable requirements and controls
→ laboratory evidence and audit → competent-authority certification decisions → production and batch monitoring
→ warehouse and logistics custody → origin customs → China-to-GCC direct movement
→ GCC receiving, distribution, retail, verification and recall support
```

PHC and JAKIM work in parallel across Perak/state and federal governance. JAKIM/JAIN/JAIM, muftis, scholars and authorised halal auditors decide certification award and revocation. AHTE connectivity is **AHTE ⇄ Direct JAKIM API ⇄ JAKIM**. AI/ML supports monitoring, prediction and preemptive strategies; people and competent authorities make decisions.
