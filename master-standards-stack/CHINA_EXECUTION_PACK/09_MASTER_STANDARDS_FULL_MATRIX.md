# 09 — MASTER JAKIM/JSM HALAL STANDARDS FULL MATRIX

## Scope

This matrix consolidates the current JSM/MySOL NSC 09 — Halal standards represented in the IQ300 operating library, including the current technical/management standards and the supporting hospitality standard used for relevant service flows. Withdrawn/replaced standards are retained separately as lineage and are not treated as current production editions.

## Standard lineage register

The IQ300 repository retains historical standards such as MS 1500:2004/2009, MS 2400-1/-2/-3:2010, MS 2200 family, MS 2200-2:2013, MS 1900:2005/2014, MS 2565:2014 and MS 2594:2015 as lineage references where relevant. Current replacements are mapped rather than duplicated as active production rules.

Known replacement relationships in the JSM catalogue include MS 1500:2019 replacing the older food editions; MS 2400-1/-2/-3:2019 replacing the older pipeline editions; MS 2634:2019 replacing the MS 2200-1 cosmetic standard; MS 2424:2019 replacing MS 2424:2012; MS 2803:2025 replacing MS 2200-2:2013; and MS 2738:2023 covering subject areas previously addressed by MS 2565:2014 and MS 2594:2015.
