# IQ300 full standards matrix

This matrix connects the applicable Malaysian standards and operating framework to requirement families, controls, HCPs, evidence, audit tests, corrective action, re-verification and certification decisions.

The controlling sources are the [master standards register](../iq300-all-jakim-ms/01_MASTER_STANDARDS_REGISTER.md), [unified clause/control/HCP matrix](../iq300-all-jakim-ms/02_UNIFIED_CLAUSE_CONTROL_HCP_MATRIX.md), [control catalogue](CONTROL_CATALOG.md), [audit test library](TEST_LIBRARY.md) and [certification decision catalogue](CERTIFICATION_DECISION_CATALOG.md).
