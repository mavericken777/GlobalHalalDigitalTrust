## 2. Revision-control implications

### 2.1 MS 1500

The platform must not back-port superseded MS 1500:2009 slaughter structure into MS 1500:2019 as if it were a current numbered clause. Current slaughter/stunning controls are maintained as a linked rule family sourced from the applicable JAKIM/DVS Malaysian Protocol, MPPHM annex/guidance, fatwa and current authority instructions.

### 2.2 MS 2400 series

The 2019 first revisions materially changed terminology and system architecture from the 2010 `halalan-toyyiban assurance pipeline` editions. The supplied licensed MS 2400 PDFs document changes including the move to `halal supply chain`, use of `sertu`, internal halal committee terminology, outsourced-provider controls and revised risk/HCP architecture. Historical controls remain versioned and must not silently overwrite the 2019 model.

### 2.3 MS 2424

Current control model uses MS 2424:2019. Historical references to MS 2424:2012 or the BM 2014 edition are stored as superseded provenance only.

### 2.4 MS 2634

MS 2634:2019 supersedes the cosmetics part of the earlier MS 2200 family. The 2019 control architecture adds modern halal-integrity/management, material provenance and manufacturing/handling controls. Confirmation in 2025 does not create a new edition; the controlled edition remains 2019 with confirmation metadata.

### 2.5 MS 2738 and MS 2803

The 2023/2025 consumer-goods architecture must be read together:

`MS 2738:2023 product/general consumable-goods requirements + MS 2803:2025 animal bone/skin/hair source/use requirements + MS 2810:2025 analytical identification where relevant`.

Standards Malaysia's 2024 withdrawal/replacement notice states that MS 2565:2014 and MS 2594:2015 requirements are covered by MS 2738:2023 as the sole reference for the relevant `skim barangan gunaan` context. MS 2803:2025 explicitly removes product requirements because MS 2738 covers them.

### 2.6 MS 2393

MS 2393:2023 replaces the 2013 edition. Ontology objects must carry edition/version because definitions can change; historical event interpretation must retain the terminology version applied at the event date.

### 2.7 MS 1900

MS 1900:2025 is a second revision replacing MS 1900:2014. The official preview states it is a modified adoption of OIC/SMIIC 18:2021 and introduces Malaysian modifications including Maqasid Shariah, `stakeholders`, `Shariah Executive`, `shariah law and fatwa`, and `Shariah Critical Control Point (SCCP)` terminology. It is intentionally broader than product-halal certification and must remain logically separate from MHMS 2020.

## 4. Governance rule

`Confirmation` is metadata on an existing edition; it is not treated as a new edition. `Revision` or `replacement` creates a new rule version and triggers change-impact assessment across controls, HCPs/SCCPs, training, evidence templates, audit tests, API rules, supplier qualification and active transaction profiles.

## 5. Change-impact event

Every standards change generates:

`REGULATORY-SOURCE-CHANGE -> SOURCE-VALIDATION -> REQUIREMENT-DIFF -> CONTROL-DIFF -> HCP/SCCP-DIFF -> EVIDENCE-DIFF -> TRAINING-DIFF -> SYSTEM-RULE-DIFF -> APPROVAL -> EFFECTIVE-DATE -> MIGRATION -> POST-CHANGE-VERIFICATION`.

Historical evidence remains attached to the edition that governed the event. No current revision rewrites historical compliance records.
