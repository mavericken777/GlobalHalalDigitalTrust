# Contributing

This is a single-maintainer specification repository.

1. Read `STATUS.md` and `GOVERNANCE.md` first.
2. Do not add language that implies live runtime, official endorsement, or executed partnerships unless the evidence file is committed in the same change.
3. Preserve `master-standards-stack/verified-2026-09-17/` byte-for-byte as the immutable 17 September 2026 baseline. Never revise it in place; record later source changes in separately dated/versioned, provenance-bearing artifacts and use current source verification for present-day applicability.
4. Open an issue before large refactors (duplicate China packs, stub expansion, CI).
5. Preferred commit tags remain those in `00_EXECUTIVE_COMMAND/commit-tag-taxonomy.json` plus `[MAJOR]` for honesty-layer changes.
