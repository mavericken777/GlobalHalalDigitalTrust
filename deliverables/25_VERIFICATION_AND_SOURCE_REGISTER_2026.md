## Evidence classification

**P1 - Primary authority:** JAKIM/JSM/SFDA/GSO source.  
**P2 - Manufacturer primary:** manufacturer's own current website/document.  
**P3 - Secondary:** trade publication, directory or marketplace.  
**P4 - Unverified statement:** user/vendor claim not yet supported by document.

Production decisions may use P1/P2 only after scope and date checks. P3/P4 are lead-generation evidence and never final compliance proof.

## Retrieval discipline

Every source-sensitive record must contain:

`URL/reference + retrieval date + document title + edition/version + source class + scope + extracted claim + verifier + next re-check date.`

## Important limitations

- The exact licensed normative text of Malaysian Standards should not be reconstructed from summaries or public snippets.
- Current authority procedures, circulars and certificates can change. The database must version and re-validate them.
- Manufacturer websites describe their own claims; exact certification scope and current validity must be obtained from the certificate/issuer.
- GCC requirements differ by destination; no single Saudi/UAE document set should be assumed universal.
