# Implementation Roadmap

## Phase 0 — Foundation (0-90 days)

- Establish governance working group.
- Confirm legal entities and contractual roles.
- Establish requirements baseline.
- Confirm pilot jurisdictions.
- Identify authoritative source documents.
- Establish security baseline.
- Build canonical data model.
- Create API gateway prototype.
- Define evidence/hash architecture.
- Prepare Sinotrans pilot process map.

## Phase 1 — Pilot (3-6 months)

Target: China -> Malaysia controlled Halal logistics corridor.

Components:
- manufacturer onboarding;
- laboratory evidence workflow;
- logistics integration;
- sovereign evidence store;
- regulator-facing evidence pack;
- retail receiving;
- consumer scan MVP.

## Phase 2 — Operational expansion (6-12 months)

- multiple manufacturers;
- multiple products;
- warehouse integration;
- retailer integration;
- AI Tier 1/2;
- exception management;
- ESG pilot;
- operational intelligence.

## Phase 3 — Network expansion (12-24 months)

- additional countries;
- additional sovereign nodes;
- additional laboratories;
- additional logistics partners;
- Tier 3 regulated workflows;
- commercial quotation engine;
- intelligence exchange.

## Phase 4 — Global platform (24-48 months)

- multi-region federated network;
- mature trust index;
- broad consumer network;
- cross-industry Halal Tayyib applications;
- long-term evidence vault;
- institutional governance council.

## Gate criteria

Each phase requires:
- legal readiness;
- security sign-off;
- data protection sign-off;
- evidence integrity testing;
- operational KPI achievement;
- incident/recovery drill;
- participant feedback;
- regulator acceptance where applicable.

## Success metrics

- onboarding time reduction;
- manual document handling reduction;
- evidence completeness;
- traceability coverage;
- recall trace time;
- exception resolution time;
- API reliability;
- security incident performance;
- participant retention;
- commercial revenue per participant;
- ESG participation;
- user satisfaction.
