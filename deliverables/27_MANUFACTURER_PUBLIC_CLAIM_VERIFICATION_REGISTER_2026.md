These are candidate categories for commercial screening, not a sales prediction or ranking. Final SKU selection is controlled by buyer demand, landed economics, destination requirements, certification scope, shelf life, MOQ and importability.

## Required document pack per candidate

`Business licence / legal entity -> factory/site evidence -> product catalogue -> formula / ingredients -> allergen statement -> Halal certificate -> certificate issuer and recognition status -> certificate validity -> exact SKU/site scope -> HACCP/BRC/FSSC/ISO evidence -> lab results where required -> Arabic label -> country-of-origin/packing data -> HS code -> shelf life/storage -> carton/pallet specification -> MOQ -> lead time -> Incoterm -> export history -> importer confirmation -> PO -> batch record -> shipment documents`

## Decision state

`PUBLIC-CLAIM-VERIFIED -> DOCUMENTS-REQUESTED -> CERTIFICATE-VERIFIED -> SKU-QUALIFIED -> DESTINATION-APPROVED -> COMMERCIAL-READY -> SHIPMENT-001-ELIGIBLE`

No candidate moves directly from public-claim verification to Shipment 001.
