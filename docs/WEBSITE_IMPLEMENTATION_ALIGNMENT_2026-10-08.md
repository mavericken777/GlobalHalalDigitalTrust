# Website implementation alignment

## Product identity

The public website presents **Global Halal Supply Chain Limited** and its Amanah / Global Halal Digital Trust platform as one connected end-to-end assurance ecosystem. Its process journey explains onboarding, product/SKU and premises, applicable standards, certified laboratories, smart audit, certification review, corrective action, production, custody, logistics, ports, GCC receiving, distribution, verification, finance/Takaful and continuous Command Center monitoring.

## Current product model

- AHTE ⇄ Direct JAKIM API ⇄ JAKIM.
- China → GCC direct.
- PHC and JAKIM work in parallel across Perak/state and federal Malaysian governance.
- JAKIM/JAIN/JAIM, muftis, scholars and authorised halal auditors decide certification award and revocation through their applicable processes.
- The platform monitors and connects certification status, evidence, custody and risk end to end; AI/ML assists with analytics and preemptive strategy recommendations.
- Use a shield-free, information-bearing animated process presentation and Arial-family sans-serif typography.

The website source and build live in the Amanah repository. This repository contains the current architecture and integration contracts. Release status is determined from the live repositories and deployment records, not from this design-alignment document.
