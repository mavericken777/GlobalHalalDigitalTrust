## Position

PHC stands **inside** the one Malaysian Halal system:

- Sultan of Perak — Head of Islam in the State
- MAIAMP / JAIPK — State religious administration, Halal files and inspections via MYeHALAL
- JAKIM — federal backbone of the same scheme
- One MS set, one procedure set, one audit–certification–compliance path

**State and Federal work hand in hand. They work as ONE** for audit, certification and compliance. PHC is the State GLC that builds and internationalises the industry on that single track.
