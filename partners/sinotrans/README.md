## Authority Boundary
Does not create Halal certification authority. Does not issue or replace customs, port, food-control, importer or destination halal decisions.

## Integration Approach
Existing Sinotrans systems are integrated through adapters/APIs rather than replaced for the pilot. Custody, seal and telemetry evidence enters the AHTE evidence graph as E4-class evidence when generated by the actual transaction and bound to shipment identity.
