# Common receiving pack — what a GCC buyer actually files

Build this once per SKU family. Re-use across all four banners. Do not invent extra lab methods.

## A. Identity

- Exporter legal name + address  
- Importer / buyer legal name (the operating company, not the banner)  
- Product name (EN + AR draft)  
- Brand / trademark owner  
- HS code  
- Country of origin  
- Lot / batch + production + expiry  
- Net weight + pack hierarchy (item → carton → pallet SSCC)

## B. Trade

- Commercial invoice  
- Packing list  
- Bill of lading / AWB  
- Certificate of origin  
- Insurance if CIF

## C. Food / Halal (destination decides the bodies)

- Halal certificate **from the body the buyer names** (often destination-accepted, not “any JAKIM paper”)  
- Health / sanitary / veterinary certificate as the category requires  
- Ingredients + process flow + allergen statement  
- Label artwork (AR + EN) matching the packed goods  
- If meat / poultry: slaughter / stunning file as the destination protocol requires — GHSC coordinates, does not certify

## D. Custody

- Seal numbers  
- Temperature log or written ambient declaration  
- Warehouse inbound / outbound if a CFS was used  
- Exception log (damage, unbind, replacement labels)

## E. Optional evidence GHSC may attach

- Lab report with method + matrix + signatory (NOT DETECTED ≠ HALAL)  
- Origin platform code mapped to GHSC lot ID  
- AmanahGraph object IDs once a feed exists

## F. What GHSC must never put in the pack

- JAKIM logo GHSC does not hold  
- Sentence that GHSC or PHC “issued” SPHM  
- Green Lane as a granted status  
- Another retailer’s name or pricing  
- SGH-FSDTI satellite / CRISPR / PQC claims as if live
