## 1. Purpose

Define cooperation for **carriage and corridor logistics only** (factory door or named CFS → port / airport → destination hold) for goods that GHSC nominates as pilot lots.

## 2. In scope

2.1 Identification of candidate lanes (origin city, gateway, mode, destination hold).  
2.2 Vehicle / container hygiene and segregation practice aligned to MS 2400-1 **as a logistics standard**, not as a JAKIM certificate.  
2.3 Seal, SSCC / GS1 identity, temperature and exception events for nominated lots.  
2.4 Handover evidence at origin gate-out and destination gate-in.

## 3. Out of scope (use the warehouse MoA)

Yard storage, CFS inventory, pick/pack, long-hold bonded storage, retail last mile.

## 4. GHSC role

Audit-readiness support; evidence pack design; coordination with shipper and receiving buyer. GHSC is not the carrier and does not issue Halal or customs documents.

## 5. Sinotrans role

Operate or subcontract the nominated lane under its own licences. Name any subcontractor in Annex A before that lane is used. Subcontracting does not move liability off Sinotrans unless a separate written novation says so.

## 6. Data (minimum fields for a pilot lot)

Lot ID · SSCC · vehicle / container ID · seal ID · gate-out time · gate-in time · temperature log or “ambient declared” · exception code.
